SecureShop Web Security Lab

Beginner → Intermediate Web Application Security
Estimated time: 45–90 minutes

Overview

This lab provides an isolated e-commerce environment to practice foundational web security concepts. The backend employs secure coding mechanisms designed to withstand and safely reject attack payloads.

Learning Objectives

  • Understand parameterization and SQL Injection mitigation.
  • Analyze JWT-based authentication mechanisms.
  • Verify Access Control and IDOR (Insecure Direct Object Reference) defenses.
  • Evaluate DOM-based XSS protections.

Testing Methodology

Use browser developer tools, cURL, or an interception proxy like Burp Suite to analyze the HTTP traffic. Compare the application's response behavior when providing valid versus anomalous input.
