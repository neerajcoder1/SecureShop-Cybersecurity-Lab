> Getting Started

Welcome to SecureShop Lab. This platform provides an isolated, secure backend designed to teach defensive programming and cyber-hygiene.

AUTHORIZED TESTING ONLY

SecureShop is intended for educational and authorized security testing.
Never test websites, APIs, accounts, or infrastructure that you do not own or have explicit permission to assess.

Web Terminal & Lab Methodology

SecureShop integrates a live Web Terminal directly into your workspace. Instead of needing external tools installed locally, you can practice reconnaissance and exploit methodologies directly in your browser using simulated tools.

> HTTP & API Inspection

Theory: Modern web applications rely on APIs (Application Programming Interfaces) to fetch data. Attackers often inspect HTTP requests to find hidden endpoints, analyze response headers for version information, or manipulate parameters (like ?id=1) to test for IDOR (Insecure Direct Object Reference) vulnerabilities.

Command: curl
Usage: curl [URL]
Description: Sends a GET request to the target URL and returns the raw HTTP response body. Useful for footprinting APIs.
Example: curl /products

> SQL Injection (SQLi)

Theory: SQL Injection occurs when untrusted user input is directly concatenated into a database query string. This allows an attacker to manipulate the query logic (e.g., bypassing login via ' OR 1=1--). SecureShop defends against this by strictly using Parameterized Queries, meaning user input is treated only as data, never as executable code.

Command: sqlmap
Usage: sqlmap -u [URL]
Description: An automated SQL injection and database takeover tool. In this lab, the terminal simulates an automated barrage of time-based, boolean-based, and error-based payloads to test the robustness of the target endpoint.
Example: sqlmap -u /login

> Challenge Validation

Theory: Security isn't just about breaking things; it's about verifying fixes. After completing your attack simulations, you must validate that the system's defenses (like JWT validation and parameterized queries) are functioning correctly and that no critical vulnerabilities remain.

Command: submit_report
Usage: submit_report
Description: Triggers the validation engine to assess your lab progress, update your live dashboard stats, and award you completion badges.
