> Getting Started

Welcome to SecureShop Lab. This platform provides an isolated, secure backend designed to teach defensive programming and cyber-hygiene.

AUTHORIZED TESTING ONLY

SecureShop is intended for educational and authorized security testing.
Never test websites, APIs, accounts, or infrastructure that you do not own or have explicit permission to assess.

How the Lab Works

The frontend communicates with a live REST API backend via HTTP requests. Your goal is to inspect this traffic, understand the authentication logic, and observe how the backend security controls neutralize common attack vectors.

Recommended Tools

  • Browser DevTools: Network tab and Console for immediate inspection.
  • Interception Proxies: Burp Suite Community Edition or OWASP ZAP.
  • Command Line: cURL or HTTPie.

First Steps

1. Navigate to the Home page and inspect the Product listing request.
2. Intercept a search query and attempt a basic injection payload.
3. Go to the Auth portal and provision a test identity.
4. Inspect the JWT returned upon successful authentication.
